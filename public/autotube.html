Unduh Video

Simpan video dari tautan file langsung yang memang boleh Anda unduh.

Format file langsung yang dikenali: MP4, WebM, MOV, M4V, dan OGV.

Pratinjau

Buka / Unduh File

Jika unduhan tidak dimulai, browser atau server sumber mungkin membatasi unduhan lintas situs. Gunakan fitur simpan yang disediakan pemilik sumber.

Catatan penggunaan

  • Halaman ini menerima URL file video langsung, bukan tautan halaman tontonan.
  • Tautan YouTube, TikTok, Instagram, dan layanan sejenis tidak diunduh di sini. Gunakan opsi unduh resmi dari platform atau pemilik konten.
  • Jangan mengunduh atau membagikan konten yang tidak Anda miliki izinnya.
